# Milestone reviews

One report per adversarial review ([ADR 46](../adr/0046-every-milestone-ends-with-an-adversarial-review.md)).
Every milestone ends with a review, run by a session that worked on none of it, as
[`docs/milestone-review.md`](../milestone-review.md) describes. Each report lists every finding, the attempt
to refute it, its verdict and what became of it, and what each axis examined and found sound.
