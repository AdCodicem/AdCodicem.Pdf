# 4. Business documents with a modern CSS subset

Date: 2026-09-12

## Status

Accepted

## Context

It covers invoices, reports, contracts and labels — the whole of the intended use — for a
fraction of the cost of a complete web engine.

## Decision

The full box model, tables, paged media, flexbox,
simple grid, inline SVG. No JavaScript.

## Consequences

Recorded so the choice is not silently revisited.
