# 7. Conformance designed in from the start

Date: 2026-09-12

## Status

Accepted

## Context

The DOM → box → marked-content traceability that PDF/UA demands cannot be retrofitted without
rewriting layout. It is therefore present from the first milestone, even though full emission of the
structure tree comes later.

## Decision

Headers and footers, numbering, links, bookmarks;
PDF/A-3 and Factur-X; tagged PDF/UA.

## Consequences

Recorded so the choice is not silently revisited.
